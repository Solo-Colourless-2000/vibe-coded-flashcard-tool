# TOTAL RECALL HTMLマニュアルの編集元

現在の配布ファイルは、`docs/TOTAL_RECALL_機能別開発_初心者向け完全開発マニュアル_20261007.html`です。表紙・タイトル・README・生成先は2026-10-07改訂版へ統一しています。HTMLを手作業で部分修正せず、下の編集元から再生成します。

## 本文の構成

- `development-guide.json`：準備、35項目の基礎語句、24章の機能別手順、切り分け、確認シナリオ。工程ごとにファイル、検索アンカー、短い抜粋、理由、期待結果、よくある間違いを持ちます。
- `beginner-workshop.mjs`：`/practice`へ小さな機能を追加する22工程。新規作成と範囲置換を区別し、型→表示→フック→採点→テストを往復します。
- `search-workshop.mjs`：完成アプリの検索へ設定を追加する5工程。純粋関数とテストを先に作り、フックと表示を往復して接続します。
- `render-development-guide.mjs`：本文と実習をHTMLへ描画し、現在のソースからアンカー位置と抜粋を解決します。一度の本番コード抜粋は36行以下です。
- `verify-workshop.mjs`：二つの実習差分を順序どおりメモリー上へ再適用し、全27途中状態をTypeScriptで検査します。最終段階をlintし、一時フォルダーで教材の採点・検索テストを実行して片付けます。アプリ本体へ実習ファイルを書き込みません。
- `source_catalog.json`：照合用付録へ収録する現行ファイルと役割。
- `manual-template.html`：目次、検索、文字サイズ、集中表示、小さなコードのコピー、モバイル、印刷スタイル。
- `generate_manual_html.mjs`：表紙、改訂本文、照合用完成ソース、旧版履歴を一つのHTMLへ生成します。
- `verify_manual_html.mjs`：生成結果、本文・実習・ソースの整合性、HTML/CSS/script、ファイル名とREADMEの参照先を検証します。
- `foundation_pages.json`：分割前の説明849ページ相当を保持する履歴資料。現行の開発手順として使わず、目次の末尾へ置き、通常検索から除外します。

## 更新

```bash
npm run manual:build
npm run manual:verify
```

`npm run check`にも`manual:verify`が含まれます。アプリを変えてアンカーが見つからなくなった場合は、本文の該当工程を先に更新します。ソースを追加した場合はカタログの一覧と責務も更新します。

基礎実習の差分を変更した場合は、後の置換アンカーとPropsの接続を確認します。各途中状態も検査するため、最後だけ動くコードでは合格しません。手順の期待結果は、その工程の状態と一致させます。

保守実習の前半3工程は事前読解、後半5工程は入力です。二つを続けて同じ変更の指示にしません。`search-workshop.mjs`は記載した変更前・変更後を照合し、実習前・途中・完了後のコピーから、教材の出発点をメモリー内だけで再構成します。5段階それぞれの再検証と、依存配列の不足を拒否する検査も含めます。実ファイルへの書き戻しや、読者の追加ファイルを上書きする処理はありません。

本文のファイル名リンクは付録の該当ファイルを展開します。「本文の工程へ戻る」は付録のスクロール中も表示し、元の工程・スクロール位置・リンクのフォーカスへ戻します。表示の検証では実際に付録の下部へ移動し、戻る操作を確認します。

完成ソースは照合資料で、本文の作業は小さな差分の順に行います。旧版資料を修正して現行手順に見せかけず、新しい構成の説明は改訂本文を直します。

配布HTMLは外部CDN・外部フォント・外部scriptを使いません。閲覧は単一ファイルで行えます。依存未導入の実習では`npm ci`にネットワークが必要であることと、HTMLのオフライン閲覧を区別します。
